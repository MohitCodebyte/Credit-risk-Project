About The Project

Turning Credit Data Into Risk Intelligence.

CreditRisk AI is a machine-learning based credit risk analytics system designed to analyze borrower characteristics, financial information, credit history and bank-level risk context to estimate default probability.

Project Objective

Built Around A Real Credit-Risk Workflow

The system brings together data preparation, exploratory analysis, feature engineering, machine learning and risk interpretation into one analytical workflow.

Analyze

Explore borrower-level financial, demographic and credit characteristics to identify patterns associated with credit risk.

Predict

Use a trained machine-learning pipeline to estimate the probability of a potential default outcome.

Interpret

Convert prediction probability into a 0–100 risk score and analytical risk categories for easier interpretation.

Data Foundation

Data With Clear Analytical Context

The project separates external banking context from borrower-level modeling data so that the analytical workflow remains transparent.

RBI Banking Data

Bank-level Gross NPA, Gross Advances and Gross NPA ratio information is used as contextual banking-risk benchmark data.

Borrower Dataset

The borrower-level dataset used by the predictive model is a simulated dataset created for project development and analytical demonstration.
